# Passport & Signature Image Transformer

A simple and user-friendly Streamlit web application that helps users transform passport and signatures into formats suitable for  online forms and applications. 

The application is designed for users who need to resize, convert, compress, and prepare images to meet common online upload requirements without needing technical knowledge.

## Features 

### Passport Photograph 
- Upload JPG, JPEG, on PNG images
- Resize images while preserving their aspect ratio
- Convert images to JPEG
- Preview the original and transformed image
- Display image dimensions, format, and file size
- Download the transformed photograph

### Signature 
- Upload JPG, JPEG, on PNG images
- Resize the signature while preserving its proportion
- Convert the signature to grayscale
- Save the transformed signature as PNG 
- Preview the original and transformed signature
- Download the transformed signature

## How it works 

The application is designed to be simple and self-explanatory.

1. Select the type of image you want to transform:
    - Passport  Photograph
    - Signature
2. Upload your image
3. The application processes the image automatically.
4. View the original and transformed images together with their respective image details
5. Download the transformed image.
